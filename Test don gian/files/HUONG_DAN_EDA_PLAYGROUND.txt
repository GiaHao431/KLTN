----------------------------------------------------------------
BƯỚC 1 — Cấu hình Simulator
----------------------------------------------------------------

Sau khi đăng nhập, nhìn vào cột bên TRÁI, mục "Testbench + Design":

  [1a] Phần "Tools & Simulators" (góc trên trái):
       → Chọn: "Cadence Xcelium" (khuyến nghị cho SystemVerilog)
         HOẶC: "Synopsys VCS"
         HOẶC: "Aldec Riviera-PRO"

       ⚠ TRÁNH dùng "Icarus Verilog (iverilog)" vì không hỗ trợ
         đầy đủ SystemVerilog (automatic tasks, $sformatf, v.v.)

  [1b] Cạnh ô simulator, tick vào:
       ☑ "Open EPWave after run"   ← để xem waveform tự động

  [1c] Trong ô "Compile options" (nếu có):
       Thêm vào: -sv   (bật chế độ SystemVerilog)
       Với Xcelium: -sv -access +rwc
       Với VCS    : -sv -debug_all

----------------------------------------------------------------
BƯỚC 2 — Nhập source code
----------------------------------------------------------------

Trên EDA Playground có 2 ô soạn thảo:
  • Ô trên  : "Testbench"   (tb_top)
  • Ô dưới  : "Design"      (design files)

Vì ta dùng bundle file 1 file duy nhất, làm như sau:

  [2a] Click vào ô "Design" (ô dưới)
       → XÓA toàn bộ nội dung có sẵn
       → PASTE toàn bộ nội dung file "eda_playground_bundle.sv"

  [2b] Click vào ô "Testbench" (ô trên)
       → XÓA toàn bộ nội dung
       → Để TRỐNG hoặc chỉ gõ:

           // Testbench is included in Design file
           // Top module: tb_ahb_slave

  [2c] Trong phần "Top entity" hoặc "Top module":
       → Gõ: tb_ahb_slave

BƯỚC 4 — Xem Waveform (EPWave)
----------------------------------------------------------------

Sau khi Run xong, tab "EPWave" sẽ mở tự động.

Các signal quan trọng cần quan sát:

  Nhóm 1 — Bus Control:
    tb_ahb_slave.HCLK
    tb_ahb_slave.HRESETn
    tb_ahb_slave.HSELx
    tb_ahb_slave.HADDR[31:0]
    tb_ahb_slave.HTRANS[1:0]
    tb_ahb_slave.HWRITE

  Nhóm 2 — Data:
    tb_ahb_slave.HWDATA[31:0]
    tb_ahb_slave.HRDATA[31:0]

  Nhóm 3 — Response:
    tb_ahb_slave.HREADYOUT
    tb_ahb_slave.HRESP[1:0]

  Nhóm 4 — SPLIT:
    tb_ahb_slave.HSPLITx[15:0]

  Nhóm 5 — DUT Internal (debug):
    tb_ahb_slave.u_dut.ps_slave[2:0]
    tb_ahb_slave.u_dut.beat_cnt[5:0]
    tb_ahb_slave.u_dut.local_addr[7:0]

Cách thêm signal vào waveform trong EPWave:
  → Click "+" ở panel bên trái
  → Tìm và chọn signal muốn xem
  → Kéo thả hoặc double-click để thêm vào viewer

Để kiểm tra TC1 (Single Write):
  → Zoom vào vùng 50ns – 150ns
  → Quan sát: HTRANS = 10 (NONSEQ) → IDLE
               HWRITE = 1
               HREADYOUT: xuống 0 (wait state ACTIVE), lên 1 (WBURST)

Để kiểm tra TC5 (SPLIT):
  → Zoom vào vùng sau ~400ns
  → Quan sát: HRESP = 11 (SPLIT) kéo dài 2 chu kỳ
               HREADYOUT = 0 ở chu kỳ 1, = 1 ở chu kỳ 2
               HSPLITx[1] = 1 trong 1 chu kỳ sau đó

----------------------------------------------------------------
BƯỚC 5 — Xử lý lỗi thường gặp
----------------------------------------------------------------

LỖI: "top module not found"
  → Kiểm tra ô "Top module" đã điền "tb_ahb_slave"
  → Đảm bảo không có lỗi compile trước đó

LỖI: "automatic tasks not supported"
  → Bạn đang dùng Icarus Verilog → đổi sang Xcelium hoặc VCS

LỖI: "$sformatf not supported"
  → Tương tự trên → đổi sang Xcelium

LỖI: "fork...join compilation error"
  → Thêm -sv vào compile options

LỖI: "timescale redefinition"
  → Xóa dòng `timescale trùng lặp (chỉ giữ 1 ở đầu file)

LỖI: TC5 FAIL — HSPLITx không assert
  → Kiểm tra HMASTER_ID có đang = 4'd1 không
  → HSPLITx[split_master_reg] = HSPLITx[1] — đúng
